# Functional requirements documents (FRD)

One folder per feature. Each has:

- `requirement.md` — the feature's requirements from the register, with status and linked tests (generated; edit `BUILD-REGISTER.md`).
- `ui-requirements.md` — the screen or topic specification from the build specification (where the specification has one).

Business rules, workflows and API requirements for a feature are in [`03-business-rules`](../../03-business-rules/), [`04-workflows`](../../04-workflows/) and [`06-api`](../../06-api/). Add `business-rules.md`, `workflow.md`, `api-requirements.md` and `acceptance-criteria.md` to a feature folder when a new feature needs its own; the all-features index is [`../README.md`](../README.md).
